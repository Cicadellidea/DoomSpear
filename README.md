# DoomSpear
Adds Chain Spear to Minecraft, so that you can fight like DOOM!

加入了DOOM Dark Age DLC 启示录里的锁链长矛。


When holding Chain Spear:
Press Hook key to shoot hook.(recommend to change to mouse right)
You can press WASD to rotaed around hook. 
Hold Hook key to lock on target when you are hooking.
Press Dash key to dash towards moving direction. (Immune to damge and get Charge if attacked by enermy)
If you have Charge:
Press Sweep key to deal hight damage to enermies in front of you.
Press Slam key when hooking to fall down and stun enermies.

Pressing Slam key or Dash key to stop hooking.

手持锁链长矛时：
按下肉钩键（建议改成鼠标右键）射出肉钩。
肉钩钩住敌人或方块以后，会将你拉向对方，你可以按住wasd移动来围绕对方旋转。
按住肉钩键可以将视野的水平方向稳定在敌人身上。
按下冲刺键可以向移动方向冲刺，短时间无敌，如果成功闪避攻击获得充能。

当你有充能时：
按下横扫键对面前敌人造成大量伤害（并造成打断）
在肉钩上时按下猛击键下坠，落地时造成伤害并击晕敌人。

（任意时刻）按下冲刺/猛击按钮可以脱离肉钩状态
